# UPLB TTBDO NextGen Agri Hackathon 2026 Deep Research Sourcebook

## Intake status

This page records the user-supplied research report as a planning-context source. It is not an official event rulebook. The report distinguishes confirmed 2026 event facts, the blank concept-note template, older TTBDO precedents, external Philippine agriculture context, technical possibilities, inference, and unresolved unknowns.

## Key findings retained

- The supplied template requires an interdisciplinary student team of 3–5 members, with an optional mentor.
- It names four focus sectors: Digital Agriculture; Smart Farming / Climate-Resilient Systems; Agri-Enterprise Development; and Value Chain Development.
- The application asks for a project title, a problem statement capped at 200 words, target users/customers/market, solution and value proposition, MVP execution strategy, technologies/software/hardware/frameworks, and a scalable business model with partners.
- Strong concepts should demonstrate one concrete end-to-end value loop, distinguish the actual user from the payer where necessary, identify existing alternatives, and use problem-linked metrics.
- Philippine prior-art and ecosystem checks matter. The report specifically flags PRiSM, Project SARAi/SPidTech, Rice Crop Manager, WateRice, PHilMech systems, DA data initiatives, SEARCA-linked platforms, and existing smart-farming/marketplace/IoT work.
- Useful prototype patterns include offline-first field workflows, calibrated IoT telemetry with alerts and history, confidence-gated computer vision with expert escalation, geospatial advisory tied to field verification, cold-chain lot tracking, and cooperative operations with audit logs.
- Relevant resource families include PSA OpenSTAT, PAGASA, NASA POWER, Earth Engine/Sentinel data, AgML, CropHarvest, PlantCV, Label Studio, farmOS, FarmBot, OpenDroneMap/WebODM, Node-RED, and ThingsBoard.

## Explicit uncertainty boundary

The report does not establish the official judging weights, pitch and Q&A durations, slide or demo limits, prototype-submission format, rules for pre-existing code or generative AI, supplied hardware or credits, IP ownership/licensing, or all eligibility/substitution rules. Older TTBDO innovation-program themes are precedent only, not confirmed NextGen Agri rules.

## Relevance to the current workspace

Fensalir already contains reusable capabilities around research, documentation, analytics, accessible UI, local-first academic systems, geospatial visualization, and evidence/provenance validation. These are capability references, not proof that an agri prototype exists or that any external dataset, model, hardware, or event rule has been verified for this competition.
